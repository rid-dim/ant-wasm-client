Autonomi WebRTC Browser Demo — no install

This web page came from an ordinary web server. The files below did not.

When you press Load, your browser opens its own direct WebRTC connections to storage nodes — no gateway, no backend, nobody in the middle relaying the data. Each file arrives as encrypted chunks pulled from several nodes at once, and every chunk is cryptographically verified and decrypted right here in this tab. This demo runs against a public test network with the same architecture proposed for the real Autonomi network.

  1. 1 · ConnectYour browser asks one node which nodes hold the file, then connects straight to those nodes.
  2. 2 · FetchThe file's encrypted chunks arrive from several nodes in parallel — nothing is proxied through a server.
  3. 3 · VerifyEach chunk is checked against its cryptographic address and decrypted in the browser. A node can refuse, but it cannot lie.
Unofficial tech demo — community project, not operated by Autonomi. Browser connects directly to demo-devnet nodes via WebRTC. Under the hood: a post-quantum tunnel (ML-KEM-768 + ML-DSA-65) to each node, BLAKE3 content verification and self-decryption in WebAssembly.
